# ✨ JeyKeys — Kids Typing Adventure & Math Playground

An engaging, magical typing adventure and math playground designed to help kids establish healthy keyboarding habits, practice arithmetic, and record their thoughts in a secure daily journal! 

🎮 **[Play JeyKeys Live Here!](https://johnonlee.github.io/JeyKeys/)** — *100% Free and Ad-Free forever.*

---

## 🌟 Key Features

### ⌨️ Typing Game
- **🖐 Finger Drills**: Learn which fingers to use for each key with color-coded keyboard visualizers.
- **🌈 Adventure Mode**: Progress through 20 themed levels, from basic home-row keys to animals and complete sentences.
- **🔥 Combo Multiplier**: Maintain typing accuracy to trigger bright combo bursts ("Fire" and "Super" mode) with satisfying retro sound effects!
- **⚡ Speed Run & Star Rush**: Race against the clock to set high scores and earn up to 3 stars per drill.

### 🔢 Math Playground
- **➕ Grouped Subgroups**: Structured across arithmetic divisions:
  - **Arithmetic Operations** (Addition, Subtraction, Multiplication, Division)
  - **Brain Training & Logic** (Fractions, Sequences, Time Reading, Mental Math)
  - **Speed Challenge** (Star Rush)
- **🕒 Interactive Analog Time**: Learn to read clock dials, hours, and minutes dynamically.

### 📔 Daily Journal
- **✍️ My Daily Diary**: Practice typing by writing stories in a daily journal.
- **🎨 Interactive Calendar**: Features a calendar showing green dots for days with saved entries.
- **📝 Creative Variety**: Rotates between 35 imaginative prompts (clubhouses, robot chores, inventing pizza toppings, dinosaur pets) to inspire writing.

### 🏅 Progression & Rewards
- **⚡ XP & Leveling**: Gain XP for typing characters, completing games, maintaining streaks, and writing journal entries. Advance through 12 custom titles from *Keyboard Newbie* to *Ultimate Genius*!
- **🔥 Login Streaks**: Keep track of consecutive days visited. Includes a weekly automatic **Streak Freeze** to protect progress if a day is missed.
- **📋 Daily Challenges**: Rotates between **3 unique daily challenges** (typing word targets, math counts, speed thresholds) with up/down arrows to navigate.
- **🏆 Badge Gallery**: Collect 21 unique achievement badges (Mental Giant, Dear Diary, Story Teller, Speed Demon) in an interactive trophies gallery.
- **👥 Multiple Profiles**: Full support for multiple kid profiles on the same device. Swapping profiles segregates their stats, streaks, badges, diaries, and levels cleanly.

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/JohnOnLee/JeyKeys.git
   cd JeyKeys
   ```
2. **Install Node.js dependencies**:
   ```bash
   npm install
   ```
3. **Start the development server**:
   ```bash
   npm run dev
   ```
4. **Build for production**:
   ```bash
   npm run build
   ```

## 🛠 Technology Stack

- **Framework**: Svelte 5 (utilizing classic legacy stores for backwards compatibility)
- **Bundler**: Vite
- **Styling**: Pure CSS3 variables & Glassmorphic variables
- **Audio synthesis**: Web Audio API (real-time generated retro oscillators—no media assets required!)
- **Storage**: LocalStorage (profile-registry scoped)
- **CI/CD Pipeline**: GitHub Actions for automated compilation check and instant deployments to GitHub Pages.
