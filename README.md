# ✨ JKeys - Kids Typing Adventure

An engaging, magical typing adventure designed to help kids establish healthy typing habits while having fun!

## 🎮 Features

- **🖐 Finger Drills**: Learn which fingers to use for each key with color-coded visual aids.
- **🌈 Adventure Mode**: Progress through 20 themed levels, from colors and animals to phrases.
- **⭐ Star Rush**: A fast-paced arcade mode to test speed and accuracy.
- **🔊 Interactive Sound**: Fun sound effects for correct and incorrect keystrokes.
- **🏆 Progression System**: Earn stars and track high scores.

## 🚀 How to Play

1. **Clone or Download** this repository.
2. Open `index.html` in your web browser.
3. Select a mode from the Main Menu:
    - **Finger Drills**: Start here to learn the basics.
    - **Adventure Levels**: Unlock new word groups and earn stars.
    - **Star Rush**: Challenge yourself against the clock!

## ⌨️ Controls

- **Standard Keyboard**: Type the characters shown on screen.
- **Esc / Menu Button**: Return to the main menu.
- **Mute Button**: Toggle sound effects.

## 🛠 Technology

Built with pure **HTML5, CSS3, and Vanilla JavaScript**. No external dependencies or frameworks required.
